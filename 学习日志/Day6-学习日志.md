## 一、知识点（6 个）

| 知识点 | 一句话 | 最容易错的点 |
| --- | --- | --- |
| `while` | 条件为 True 就重复执行 | 循环体里必须有"让条件变假"的语句，否则死循环 |
| `while` 嵌套 | 外层管天、内层管花 | 内层初始化 `j = 1` 必须写在外层循环体**里面** |
| `for` | 挨个取出数据，不用自己写自增 | 字符串也能遍历：`for x in "lvyongheng"` |
| `range` | 造一串数字 | **左闭右开**：`range(1, 100)` 只到 99 |
| 循环变量作用域 | 出了循环依然存在 | 停在最后一个值；序列为空则保留旧值 |
| `continue` / `break` | 跳过本次 / 结束循环 | 两个都**只管最近一层**，其后的代码一律不执行 |

## 二、核心语法

```python
# while：不知道要跑几次时用
i = 0
while i < 100:
    print("python")
    i += 1              # ⭐ 忘了这行 = 死循环（按 Ctrl+C 停）

# while 嵌套
i = 1
while i <= 100:
    j = 1               # ⭐ 必须写在外层循环体里面
    while j <= 10:
        print(f"第{i}天，第{j}朵花")
        j += 1          # 内层自己加
    i += 1              # 外层自己加

# for：挨个取出数据
for x in "lvyongheng":
    print(x)            # l v y o n g h e n g

for i in range(1, 101): # 跑 100 次：1…100
    print(i)

# while True + break：无限次机会的标准写法
while True:
    guess = int(input("猜一个数："))
    if guess == num:
        break           # ⭐ 少了这句，猜中了也退不出来
```

## 三、range 三种写法（实测）

| 写法 | 生成的数字 | 用途 |
| --- | --- | --- |
| `range(10)` | 0,1,…,9 | 跑 10 次 |
| `range(5, 10)` | 5,6,7,8,9 | 指定起点 |
| `range(1, 11, 3)` | 1,4,7,10 | 指定步长 |
| `range(10, 0, -1)` | 10,9,…,1 | 倒着数 |

> 口诀：**左闭右开**。要"从 1 到 100"必须写 `range(1, 101)`。

## 四、continue 和 break 的区别（实跑对照）

```python
for i in range(1, 6):
    print("1")
    for i in range(1, 4):
        print("2")
        continue        # 换成 break 就是另一张图
        print("3")      # 永远不执行
    print("4")
```

| 关键字 | 内层 `2` 打印 | 外层 `4` 打印 | 结论 |
| --- | --- | --- | --- |
| `continue` | 3 次 | 5 次 | 跳过本次，进入下一轮 |
| `break` | 1 次 | 5 次 | 结束循环，但**只结束内层** |

## 五、6 个实战案例

| 案例 | 用到的知识 | 结果 / 关键点 |
| --- | --- | --- |
| 1–100 求和 | `while` + 累加 | **5050**；累加变量放循环外 |
| 猜数字（无限次） | `while True` + `elif` + `break` | 每次提示大了/小了，猜中后报次数 |
| 九九乘法表 | 嵌套 + `end=''` + `\t` | 内层 `j <= i` 才是三角形；空 `print()` 换行 |
| 数一数有几个 o | `for` 遍历 + `if` 计数 | "lvyongheng is a good boy" → **4** 个 |
| 统计偶数个数 | `range` + `%` | 见坑 #4 的差一问题 |
| 发工资 | `continue` + `break` | 绩效 < 5 跳过**且不扣钱**；余额为 0 时 `break` |

## 六、今天踩的坑

| # | 坑 | 正确做法 |
| --- | --- | --- |
| 1 | `while` 忘了 `i += 1`，终端刷屏 | 循环体里必须有"让条件变假"的语句；`Ctrl+C` 停 |
| 2 | 把 `break` 拼成 `brake` | 正确拼写 `break`（有 `.py` 后缀时编辑器会直接画红线） |
| 3 | `while flag:` 里忘了 `flag = False`，猜中也不停 | 改用 `while True` + `break`，只有一个出口 |
| 4 | 以为 `range(1, 100)` 能到 100 | 左闭右开，写 `range(1, 101)` |
| 5 | 嵌套两层都用 `i` | 内层换 `j`，否则外层的 `i` 被覆盖 |
| 6 | 内层初始化写在外层循环外面 | 内层只会跑第一轮 |
| 7 | 以为循环变量出循环就没了 | `for` 的变量循环后仍在（停在最后一个值） |
| 8 | 用 `sum` 当变量名 | 会盖住内置函数，改用 `total` / `count` |
| 9 | `import random` 写在循环里 | 提到文件开头 |
| 10 | 统计字符靠心算 | 用 `s.count("o")` 交叉验证（那题是 4 个，不是 3 个） |
