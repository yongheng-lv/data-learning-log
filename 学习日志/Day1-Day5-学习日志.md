## 二、每天的知识点

### Day 1（10-14）print 与注释

```python
print("Hello")        # 输出文字，引号必须是英文
print(666, 13.14)     # 输出多个内容，逗号会自动加一个空格
# 这是单行注释，不会运行
```

- `print()` 是函数，括号里放要输出的内容。
- 字符串要加引号；中文引号 `“”` 会直接报错。
- 注释用 `#`；三引号 `"""..."""` 常用来写多行说明。

### Day 2（10-16）字面量与变量

```python
666                   # 字面量：写死的值，单独一行不会输出
money = 50            # 变量：给 50 贴个名字叫 money
money = money - 10    # 先算右边，再把结果存回左边
print(money)          # 40
```

- 变量 = 名字 + 值，格式 `变量名 = 值`。
- 再次赋值会覆盖旧值。
- 先定义、后使用，否则 `NameError`。

### Day 3（10-17）数据类型、转换、标识符

```python
print(type(666))        # <class 'int'>
print(type(13.14))      # <class 'float'>
print(type("黑马"))      # <class 'str'>

print(int("11"))        # 11
print(str(11))          # 11（类型变成 str）
print(float("13.14"))   # 13.14
```

- 三种基本类型：整数 `int`、小数 `float`、文字 `str`。
- `type()` 会返回结果，能存进变量；`print()` 只打印，不返回。
- 命名规则：字母 / 数字 / 下划线，不能数字开头，不能用关键字，区分大小写。
- 命名规范：见名知意、全小写、单词间用下划线（如 `stock_price`）。

### Day 4（10-17）运算符、字符串、格式化、input

```python
print(6 / 2)     # 3.0  除法结果一定是小数
print(6 // 2)    # 3    取整除
print(5 % 2)     # 1    取余
print(2 ** 3)    # 8    幂
num = 1
num += 1         # 等价于 num = num + 1
```

字符串：

```python
name = "吕永恒"
print("我叫" + name)      # 拼接：两边都得是字符串
print("我叫%s" % name)    # %s 占位
print(f"我叫{name}")      # f-string（推荐）
```

- 三种引号都行：`'...'`、`"..."`、`'''...'''`。
- 引号嵌套：里面换一种引号，或用 `\"` 转义。
- `%s` 万能、`%d` 整数、`%f` 小数（默认 6 位）。
- 精度：`%.2f` 保留 2 位；`%7.2f` 宽度 7、精度 2。
- `input()` 读键盘输入，**拿到的永远是字符串**，要算数得先 `int()`。

### Day 5（10-18）bool 与 if 判断

```python
age = int(input("请输入年龄："))
if age >= 18:
    print("成年")
else:
    print("未成年")
```

```python
score = 85
if score >= 90:
    print("优秀")
elif score >= 60:
    print("及格")
else:
    print("不及格")
```

- `True` / `False` 是布尔值，首字母大写。
- 比较运算符：`==` `!=` `>` `<` `>=` `<=`。
- `if` 后面要冒号 `:`，下面一行要缩进 4 个空格。
- `if / elif / else` 从上往下判断，命中一个就结束。
- 嵌套：外层条件成立，才会看内层条件。

## 四、易错点清单（我踩过的坑）

| # | 坑 | 正确做法 |
| --- | --- | --- |
| 1 | 用了中文引号 / 括号 | 切到英文输入法 |
| 2 | `input()` 直接和数字比较 | 先 `int(input(...))` |
| 3 | `=` 和 `==` 混用 | 赋值用 `=`，比较用 `==` |
| 4 | `int("13.14")` 报错 | 先用 `float()`，再转 `int()` |
| 5 | 以为 `int(13.99)` 得 14 | 实际得 13，直接截断 |
| 6 | `%f` 输出一堆 0 | 用 `%.2f` 指定精度 |
| 7 | `if` 后忘冒号 / 缩进不对 | 冒号 + 4 个空格 |
| 8 | `"我叫" + 18` 报错 | 用 f-string，或 `str(18)` |
| 9 | 只写 `666` 以为会输出 | 字面量必须交给 `print()` |
| 10 | 变量没定义就使用 | 先赋值，再使用 |
